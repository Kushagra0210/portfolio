## The problem

Air-quality datasets are approachable enough to learn from and messy enough to punish shortcuts. This independent project turns a city-level historical dataset into an exploratory application for comparing regression approaches and inspecting a prediction—not a production forecasting claim.

The app keeps the workflow compact: load and validate the dataset, prepare features, train cached model pipelines and expose comparison and prediction views through Streamlit.

## Implementation details

The application uses pandas for tabular preparation, scikit-learn pipelines for repeatable transforms and estimators, XGBoost as an additional ensemble comparison, and Streamlit for exploratory controls and charts. Dependencies are pinned for a reproducible Community Cloud build.

## Testing

Deployment hardening checks dataset loading, required columns, model preparation and a minimal prediction path. The UI also has explicit loading and error states so infrastructure failure is distinguishable from an empty result.

## Limitations

- The historical city-day dataset is not a live sensor feed.
- Random splitting can overstate generalization when temporal drift matters.
- No accuracy or public-health impact claim is made until a documented evaluation protocol supports it.
- Missing pollution and weather context constrains real-world forecasting value.
